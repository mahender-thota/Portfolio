MAHENDER THOTA — PERSONAL PORTFOLIO

FILES
- index.html: edit your name, About, Experience, Education, skills, projects and links.
- style.css: edit the design, responsive layout and theme colors.
- script.js: mobile navigation and current footer year.

COLOR THEME
- Sage grey: #DCE0D9
- Warm cream: #FBF6EF
- Sand beige: #EAD6C1
- Dark text: #1F2E26
- Accent: #BD7840 (small accent color for links and buttons)

RUN LOCALLY
1. Extract the ZIP.
2. Open the folder in VS Code or IntelliJ.
3. Open index.html in your browser. For best results, use a local static server.

BEFORE PUBLISHING
1. Search index.html for YOUR_EMAIL@example.com and replace it with your email.
2. Replace YOUR-LINKEDIN-USERNAME, YOUR-GITHUB-USERNAME and YOUR-GITLAB-USERNAME with your actual profile names.
3. Update education, dates, experience bullets, project descriptions, project repository URLs and resume link to reflect your real details.
4. Add your resume PDF to this folder and link the Download Resume button to that file if desired.

LOGOS
Technology logos use Devicon's public CSS CDN. A connection to the internet is required to load those logos. Each skill logo links to the relevant official website or documentation and opens in a new tab.

RESPONSIVE
The page includes layouts for desktop, tablet and mobile, plus a mobile navigation toggle.
